## Objective

Create the `crux-skill-memory-index` skill with a Python script that recursively scans all memory files, joins with reference tracker data, and produces a prioritised index at `.crux/memory-index.yml`.

## Deliverables Checklist
- [ ] `.cursor/skills/crux-skill-memory-index/SKILL.md` — skill definition describing:
  - When and how to invoke the index rebuild script
  - The index file format and prioritisation rules
  - How agents use the index for memory discovery
- [ ] `.cursor/skills/crux-skill-memory-index/scripts/memory-index.py` — Python script that:
  - Recursively scans `memoriesDir` for `*.memory.md` and `*.memory.crux.md` files
  - Parses YAML frontmatter from each file
  - Joins with matching `*.refs.yml` tracker files from `trackingDir`
  - Produces `.crux/memory-index.yml` sorted by:
    1. `typePriority` order (configurable, default: core > redflag > goal > learning > idea > archived)
    2. `strength` descending
    3. `references` descending
  - Includes agent-scoped memories with correct relative file paths
  - Handles missing/corrupt files gracefully (skip with warning)
  - Reads config from `.crux/crux-memories.json`
  - Header comment: `# Generated by crux-skill-memory-index — do not edit manually`
  - Includes rebuild timestamp
- [ ] Index entry schema: `slug`, `title`, `description`, `type`, `strength`, `references`, `tags`, `file`

## Implementation Notes

Reference `docs/crux-memories.md`:
- "Memory Index" section for the full index format and prioritisation rules
- Index entry example in the spec

The script should:
1. Read `.crux/crux-memories.json` for `storage.memoriesDir`, `storage.indexFile`, `referenceTracking.trackingDir`, and `typePriority`
2. Walk directories recursively using `os.walk()` or `pathlib.Path.rglob()`
3. Parse YAML frontmatter (between `---` markers) using `yaml.safe_load()`
4. For each memory, look for matching `{slug}.refs.yml` in `trackingDir`
5. Build the combined entry and sort by priority rules
6. Write output YAML using `yaml.dump()` with explicit string quoting for titles/descriptions

Follow the pattern of existing skill scripts (e.g., `.cursor/skills/crux-utils/scripts/crux-utils.sh` but in Python).
