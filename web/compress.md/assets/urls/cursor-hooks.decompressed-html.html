Cursor Hooks

Observe, control, and extend the Cursor agent loop via custom scripts. Spawned processes communicate over JSON via stdio, running before or after agent stages.

JSON over stdio pre / post hooks cmd & prompt types Tab + Agent scopes

⚡ Capabilities

Context Injection

Inject context at session start to prime agent behavior

Subagent Control

Control and gate Task tool subagent spawning

Risk Gating

Gate risky operations like SQL writes before execution

PII / Secret Scanning

Scan for PII and secrets in tool inputs and outputs

Analytics

Add analytics tracking across agent actions

Post-edit Formatters

Run code formatters automatically after file edits

⚙ Configuration

Hooks are defined in hooks.json files (schema version 1). Location determines scope and priority.

⟡ Hook Types

Command

Shell script. Receives JSON on stdin, writes JSON to stdout. Exit 0 = success (use JSON output). Exit 2 = deny (permission denied). Other exit = fail, proceed (fail-open default).

Prompt

LLM-evaluated natural language condition. Optional model override (fast model default). $ARGUMENTS auto-replaced with hook input JSON. Returns {ok, reason?}.

◈ Per-Script Configuration

command string (required) Script path or shell command to execute
type "command" | "prompt" Hook type. Defaults to "command"
timeout number (seconds) Platform default timeout for script execution
loop_limit number | null Max iterations for stop/subagentStop. Default 5 (Cursor), null (Claude Code)
failClosed boolean = false If true, block operation on failure (crash, timeout, bad JSON)
matcher string | null Filter expression to control when hook fires

◉ Agent Hooks

Scopes: Tab = inline completions. Agent = Cmd+K and Agent Chat.

Tool Use Hooks

▶ preToolUse blocking

Fires before any tool execution. Can allow, deny, or modify the tool input.

InputDescription
tool_nameName of the tool being invoked
tool_inputObject — the tool's input parameters
tool_use_idUnique tool use identifier
cwdCurrent working directory
modelModel being used
agent_messageThe agent's message context
OutputDescription
permission"allow" | "deny"
user_messageOptional message shown to user
agent_messageOptional message to agent
updated_inputOptional modified tool input object
▶ postToolUse post-exec

Fires after successful tool execution. Can inject additional context or replace MCP tool output.

InputDescription
tool_nameName of the tool
tool_inputTool input parameters
tool_outputString (JSON) — the tool's result
tool_use_idUnique identifier
cwdWorking directory
durationExecution duration in milliseconds
modelModel used
OutputDescription
updated_mcp_tool_outputMCP only — replaces the tool output
additional_contextString injected after tool result
▶ postToolUseFailure observe

Fires when a tool fails, times out, or is permission-denied. Output is empty (observe only).

InputDescription
tool_nameName of the failed tool
tool_inputTool input parameters
tool_use_idUnique identifier
cwdWorking directory
error_messageError description
failure_type"error" | "timeout" | "permission_denied"
durationDuration in milliseconds
is_interruptBoolean — was this an interrupt

Subagent (Task) Hooks

▶ subagentStart blocking

Fires before a Task tool subagent is spawned. Can allow or deny.

InputDescription
subagent_idUnique subagent identifier
subagent_type"generalPurpose" | "explore" | "shell" | ...

git_branchOptional git branch context
OutputDescription
permission"allow" | "deny" (ask → deny)
user_messageOptional user-facing message
▶ subagentStop post-exec

Fires when a subagent completes. Can trigger auto-followup. Subject to loop_limit (default 5).

InputDescription

loop_countIteration count (starts at 0)
modified_filesArray of modified file paths
agent_transcript_pathOptional transcript path
OutputDescription
followup_messageAuto-continues agent (only when status = completed)

◆ Matchers

Matchers filter which hooks fire based on event-specific criteria.

beforeShell / afterShellMatches on command string
subagentStart / subagentStopMatches on subagent_type
preToolUse / postToolUse / postToolUseFailureMatches on tool_name: Shell, Read, Write, Grep, Delete, Task, "MCP: <name>"
afterFileEditMatches on tool_type: TabWrite, Write
beforeReadFileMatches on tool_type: TabRead, Read
afterAgentThoughtMatches: "AgentThought"
afterAgentResponseMatches: "AgentResponse"
stopMatches: "Stop"
beforeSubmitPromptMatches: "UserPromptSubmit"

⬡ Environment Variables

Available to all hook scripts via process environment.

CURSOR_PROJECT_DIRWorkspace root (always set)
CURSOR_VERSIONCursor version string (always set)
CURSOR_USER_EMAILUser email (if logged in)
CURSOR_TRANSCRIPT_PATHTranscript path (if enabled)
CURSOR_CODE_REMOTE"true" if remote workspace
CLAUDE_PROJECT_DIRAlias for compatibility

Environment variables set in sessionStart output propagate to all subsequent hooks in the session.
