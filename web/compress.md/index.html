Quickstart

Installation

Prerequisites: Cursor IDE (no runtime dependencies for agent install)

Paste into Cursor chat 
Fetch https://raw.githubusercontent.com/zotoio/CRUX-Compress/main/install.crux.md, read it, and follow its instructions to install CRUX Compress into this project.

Can't fetch URLs? Save install.crux.md to your project and reference it, or paste its contents into chat.

Alternative: Terminal (requires python3) 
curl -fsSL https://raw.githubusercontent.com/zotoio/CRUX-Compress/main/install.py | python3 -

Usage

  1. 1
    Add crux: true to your rule file's frontmatter
  2. 2
    Run /crux-compress ALL in Cursor
  3. 3
    Watch your context breathe

Optional: add command-parameter plugins with /crux-compress ALL --plugin quality-gate.
