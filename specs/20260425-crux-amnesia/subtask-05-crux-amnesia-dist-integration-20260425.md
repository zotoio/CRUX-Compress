## Implementation Notes
- `DIST_FILES` is the canonical list of files included in the `CRUX-Compress-v{version}.zip` release archive
- The script also generates `.crux/dist-manifest.json` (used by the installer's `get_release_files()`) and `.crux/crux-release-files.json` (per-version checksums)
- Adding a file to `DIST_FILES` automatically propagates to the dist manifest and release checksums — no other files need manual updates for distribution
- The zip contents protection rule (`.cursor/rules/zip-contents-protection.md`) normally requires explicit user permission to modify `DIST_FILES` — this addition was explicitly requested

Other memory commands (`crux-dream`, `crux-forget`, `crux-recall`, `crux-remember`, `crux-meditate`) were already in `DIST_FILES`, but amnesia was overlooked. This meant users installing via the release zip would not get the amnesia command, though the installer's `DEFAULT_MEMORIES_CONFIG` referenced it.
